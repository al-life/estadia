# Estadia — resultados aprovados

- [x] Workspace em tela única com painéis de origem e destino lado a lado em desktop/tela grande/Galaxy Z Fold e fluxo compacto em etapas no celular; navegação entre anúncios, migrações, plataformas e ajuda. Interface nativa Expo também funciona no navegador.
- [x] Contas: links para os domínios oficiais de Airbnb e Booking.com, sem armazenar senhas, sem falsos estados conectados, sem CAPTCHA/MFA contornado. Destacar importação oficial por link no cadastro quando disponível. A API de parceiro indisponível permanece explicitamente não configurada.
- [x] Importação local: formulário guiado, colagem de JSON e arquivo JSON com modelo documentado; um ou vários anúncios selecionáveis, sessão de migração com progresso, busca e filtro. Exemplos identificados como demonstração e separados dos dados reais. Dados persistidos apenas no dispositivo, pois os power-ups de base/cofre não foram selecionados.
- [x] Mapeamento assistido de título, descrição de referência, tipo, endereço, comodidades, regras, capacidade, quartos e políticas; comparar origem preservada com destino editável. Não inferir dados ausentes.
- [x] Fotos locais: anexar arquivos, preservar ordem e legendas, ordenar e remover com confirmação, indicar ausências e formatos/tamanho/resolução incompatíveis. Nenhuma foto apresentada como enviada à Booking.com. Pacote exportado inclui arquivos anexados e um manifesto ordenado.
- [x] Validação prévia: pendências acionáveis para campos e fotos obrigatórios, políticas e revisão final; limites de fotos baseados na documentação oficial; Booking.com tem a decisão final sobre requisitos. Rascunho incompleto não é marcado como pronto; conclusão declarada no site externo é diferenciada de completude do backup local.
- [x] Revisão e saída: pacote ZIP preenchido, dados JSON e checklist de conclusão quando API indisponível, com progresso por anúncio e instruções. Registrar pacote preparado separadamente de publicação; publicação apenas no site oficial pelo usuário. Sem botão que finja publicar.
- [x] Resumo final: lista de sessões locais, resultado de cada anúncio, itens preparados, pendências e retomada. Confirmação local de cadastro concluído explicitamente declarada pelo usuário, sem alegar verificação por API.
- [x] Identidade Estadia: ícone nativo próprio, tons de verde-petróleo e superfícies marfim, tipografia editorial e navegação clara com controles acessíveis. Configuração de orientação adaptável sem travar retrato.
- [x] Validação técnica: TypeScript e 22 testes dos fluxos de importação/mapeamento/validação/backup, revisão somente leitura por agente e correção dos achados concretos, serviços Metro 8081 e API 3000 com HTTP 200 público, bundles Web e Android exportados com sucesso. Checkpoint deve ser salvo após este registro. Expo Go/APK instalado não foram verificados; build APK exige ação de dispositivo no Dashboard e não é alegado como produzido.

## Ajuste solicitado durante o desenvolvimento

- [x] Prioridade: o Booking.com já importa quase tudo, mas o usuário perde o login antes de concluir, e às vezes recebe mensagem de conta desativada. O Estadia preserva cada edição e o andamento local, registra o link/ID do cadastro Booking.com para retomada, mostra claramente o que foi salvo localmente versus confirmado manualmente no Booking.com, e orienta evitar criar novo cadastro inadvertidamente na retomada. O checklist é persistido por anúncio, com interrupção/retomada e último salvamento.
- [x] Abrir o Booking.com no navegador externo habitual, e não em iframe/incognito/WebView com sessão isolada; não alegar manter cookies do Booking.com, renovar a sessão ou reativar a conta. Ajuda objetiva para conta desativada e links oficiais. Nenhum preenchimento de identidade, contrato ou publicação executado automaticamente.
- [x] Recuperação adicional: restaurar ZIP com dados, fotos, notas, referências e checklist; IDs remapeados para adicionar cópias sem sobrescrever anúncios locais existentes. Configurações acessíveis no desktop e, no celular, tocando a marca no cabeçalho.

## Limites da entrega

Esta versão preserva o trabalho registrado no Estadia, não os dados que existam somente no formulário externo do Booking.com. Não controla duração de login, não reativa conta desativada e não possui acesso API oficial às contas. Não há sincronização automática entre dispositivos. Fotos e rascunhos locais podem ser apagados ao limpar dados do navegador ou desinstalar; o ZIP é o caminho de cópia e recuperação manual. A geração de bundles não prova execução em um aparelho físico.
